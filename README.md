# AI Telegram Assistant — «Центр Красок #1»

Telegram-бот с AI-ассистентом, который отвечает на вопросы о компании
[centr-krasok.kz](https://centr-krasok.kz) в формате обычного чата.
Ответы строятся **только на основе собранной базы знаний** (RAG), что ограничивает
галлюцинации модели.

Бот отвечает двумя путями:

- **Самые популярные вопросы** — кнопками. Top-5 частых вопросов показывается прямо в
  чате и сортируется по реальной популярности нажатий (most frequent), ответ выдаётся
  мгновенно из кэша.
- **Любые релевантные вопросы** — свободным текстом. На вопрос, заданный обычным
  сообщением, бот находит подходящие фрагменты базы знаний компании и отвечает по ним
  (бренды, услуги, доставка, оплата, офис, программы для дизайнеров/строителей и т.д.).
  Если вопрос не относится к компании — вежливо отказывает, не выдумывая.

## Стек

- **aiogram** (polling) — Telegram-бот, работает в формате чата
- **Google Gemini** — `gemini-2.5-flash` (ответы) + `gemini-embedding-001` (эмбеддинги, 3072 dim)
- **LangChain** — обвязка над LLM и эмбеддингами
- **PostgreSQL + pgvector** — векторное хранилище для семантического поиска
- **SQLAlchemy** — ORM и работа с БД
- **Docker Compose** — запуск всего одной командой

## Как работает (архитектура)

```
                 ingest.py (разово)
data/company.md ──► чанки ──► эмбеддинги (Gemini) ──► pgvector

Пользователь ─► Telegram ─► bot.py ─► rag.answer():
    1. эмбеддинг вопроса
    2. поиск top-k похожих чанков в pgvector (косинусное расстояние)
    3. фильтр по порогу релевантности (отсекает вопросы не по теме)
    4. Gemini генерирует ответ строго по найденному контексту + история диалога
```

**Защита от галлюцинаций:**
- модель получает в системном промпте только найденный контекст и инструкцию
  отвечать исключительно по нему;
- низкая `temperature`;
- если ни один чанк не проходит порог близости — бот честно отвечает, что данных нет,
  и даёт контакты, не обращаясь к модели.

**Контекст диалога:** последние реплики на каждый чат хранятся в памяти и передаются модели.

## Доп. фичи (UX, скорость, продакшн)

- **Стриминг ответа.** Текст «печатается» по мере генерации (как в ChatGPT) —
  правки сообщения throttled, чтобы не упираться в лимиты Telegram.
- **Top-5 частых вопросов кнопками.** На `/start` и под каждым ответом показывается
  инлайн-клавиатура с частыми вопросами («Кто мы?», «Что предлагаем?», «Доставка»,
  «Где офис?», «Для дизайнеров»). Тапнул — получил ответ, печатать не нужно.
- **«Most frequent» по-настоящему.** Каждое нажатие кнопки считается в БД (`faq_stats`),
  и top-5 сортируется по реальной популярности. Все свободные вопросы пишутся в
  `question_log` для аналитики частотности.
- **Мгновенный ответ по кнопке.** Ответы на FAQ кэшируются в БД, поэтому тап по кнопке
  отдаёт готовый ответ **без вызова LLM**.
- **Оценка ответа 👍/👎.** Под каждым ответом — кнопки оценки; оценки сохраняются в
  таблицу `feedback` (петля контроля качества).
- **Команда `/top`.** Показывает реальную статистику самых частых вопросов из лога.
- **Антиспам (rate limiting).** Не более N сообщений за окно секунд на чат
  (настраивается в `config.py`).
- **Быстро сразу после старта.** При запуске бот в фоне прогревает кэш FAQ и заодно
  «разогревает» соединение с Gemini — первый же вопрос отвечается заметно быстрее.
  Кэш инвалидируется автоматически при переиндексации базы (`ingest`).

## Структура

```
app/
  bot.py       — Telegram-бот (aiogram): чат, FAQ-кнопки, прогрев
  rag.py       — поиск + генерация ответа (Gemini, pgvector)
  faq.py       — частые вопросы, кнопки, кэш ответов и статистика нажатий
  ingest.py    — индексация базы знаний в pgvector
  scraper.py   — опциональный парсер сайта (в data/_scraped_raw.md на ревью)
  db.py        — SQLAlchemy: чанки, статистика FAQ, лог вопросов
  config.py    — настройки из .env
data/company.md — структурированная и очищенная база знаний о компании
db/init.sql     — включение расширения pgvector
docker-compose.yml, Dockerfile, requirements.txt
```

## Запуск через Docker (рекомендуется)

1. Получите токен бота у [@BotFather](https://t.me/BotFather) и
   API-ключ в [Google AI Studio](https://aistudio.google.com/apikey).
2. Создайте `.env` из примера и впишите ключи:
   ```bash
   cp .env.example .env
   # отредактируйте TELEGRAM_BOT_TOKEN и GOOGLE_API_KEY
   ```
3. Поднимите всё:
   ```bash
   docker compose up --build
   ```
   Postgres стартует → `ingest` индексирует базу знаний → запускается `bot`.
4. Напишите боту в Telegram любой вопрос.

Переиндексировать базу после правки `data/company.md`:
```bash
docker compose run --rm ingest
```

## Локальный запуск (без Docker для бота)

```bash
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env            # впишите ключи

# поднять только Postgres с pgvector
docker compose up -d db

python -m app.ingest            # индексация
python -m app.bot               # запуск бота
```

## Примеры вопросов

- Чем занимается компания?
- Какие услуги предоставляете?
- Где находится офис в Алматы?
- Какие бренды красок есть?
- Как происходит доставка и оплата?
- Есть ли программа для дизайнеров?
- Какие есть вакансии?

## Обновление базы знаний

`data/company.md` — основной, вручную очищенный источник. Чтобы подтянуть свежие данные
с сайта, запустите парсер и перенесите нужное в `company.md`:
```bash
python -m app.scraper           # результат в data/_scraped_raw.md (ingest его не берёт)
```
